# 🌊 IndieScope — Steamインディー市場の海図

**「どの海で戦うかを、数字で決める。」**

Steamのインディーゲーム市場をジャンル別に分析し、競合数・ヒット率・推定売上から
参入すべきジャンル（＝海）を見つけるための市場調査ツールです。

🔗 **https://jdrhfskaaa-ctrl.github.io/indie-scope/**

## 特徴

- **海図（Ocean Map）** — 全ジャンルを競合度でマッピング。ブルー/イエロー/レッドオーシャンを一目で判定
- **ジャンル比較表** — 競合数・ヒット率・中央値レビュー・価格相場・推定売上を横断比較（ソート可能）
- **ジャンル詳細** — レビュー数分布・価格分布・売れ筋トップ12と推定累計売上
- **日本語ネイティブ** — 全UIとデータ表記が日本語・円建て

## データの考え方

| 指標 | 根拠 | 信頼度 |
|---|---|---|
| レビュー数 | SteamSpy実測値 | 高 |
| 価格 | SteamSpy実測値（円） | 高 |
| ヒット率 | レビュー1000件超の割合 | 高 |
| 推定売上 | レビュー数×35×価格（Boxleiter法） | 概算 |
| 海の判定 | 競合数×ヒット率による機械的目安 | 参考値 |

推定オーナー500万以上のタイトルはAAAとして分析から除外しています。

## アーキテクチャ

```
GitHub Actions（毎日）
  └─ SteamSpy API取得（フォールバック検出・タグ名候補リトライ付き）
       └─ scripts/aggregate.py で集計
            └─ data/stats.json（約20KB）を生成・コミット
                 └─ フロントエンド（index.html単体）が読み込み
```

生データ（約37MB）はリポジトリに保持せず、集計済みの軽量JSONのみを配信します。
